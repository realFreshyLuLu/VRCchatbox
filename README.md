# VRC Chatbox

**适合 VRChat 无言势玩家在 VR 状态下使用手机打字，与朋友交流的工具。**

**简体中文** · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

VRC Chatbox 是面向 Windows 的 VRChat OSC 文字聊天工具。程序在电脑上运行，你可以通过浏览器输入消息，也可以用同一局域网内的手机访问。支持翻译预览、发送历史、常用短语和界面外观设置。

> 下载 Windows 发布包即可使用，**无需安装 Python**。请从仓库的 **Releases** 区域下载 `VRCChatbox-1.4-Windows-x64.zip`；仓库源码压缩包用于开发和自行构建。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 跨设备输入 | 电脑浏览器或同一局域网的手机浏览器均可访问 |
| 手动打开页面 | 启动后显示本机和局域网访问地址，不自动打开浏览器 |
| 四语言界面 | 简体中文、英语、日语、韩语；保存选择，默认读取主机系统显示语言 |
| 多服务翻译 | MyMemory、DeepL、Azure Translator、OpenAI 兼容接口 |
| 翻译后检查 | 译文先进入输入框，可编辑后再发送，不自动发送 |
| 双语消息 | 原文与译文、仅译文、仅原文；双语顺序可调整 |
| 历史与短语 | 电脑端保存并在设备间共享；支持复制、编辑和重发，历史可导出 TXT |
| 外观设置 | 深浅色主题、颜色、头像和背景图片 |

本工具用于发送文字，**无法接收其他 VRChat 玩家发来的消息**。发送记录表示程序已提交消息，不代表其他玩家已收到。

## 快速开始

### 1. 下载并启动

1. 下载 Releases 中的 Windows x64 压缩包。
2. 将**整个压缩包**解压到你有写入权限的文件夹。
3. 双击 `VRCChatbox.exe`，保持控制台窗口打开。

请保留 EXE 旁的 `_internal` 文件夹。不要直接在压缩软件中启动，也不要只复制 EXE。

### 2. 打开聊天界面

启动成功后，控制台会显示访问地址，例如：

```text
This computer: http://127.0.0.1:5000/
LAN devices:   http://192.168.1.8:5000/
```

这些地址仅为示例，请使用程序实际显示的地址。

- **在这台电脑上使用：** 将本机地址复制到浏览器。
- **在手机或其他设备上使用：** 与电脑连接同一局域网，再打开局域网地址。手机上的 `127.0.0.1` 指向手机自身，不能用于访问电脑。
- **显示多个地址：** 电脑可能有多个网卡或 VPN，请选择与手机处于同一网段的地址。

### 3. 启用 VRChat OSC

在 VRChat 的 OSC 设置中启用 OSC。默认发送目标为 `127.0.0.1:9000`，适用于 VRChat 与本程序运行在同一台电脑的情况。

输入消息，点击“发送”。需要翻译时先点击“翻译”，检查结果后再发送。

## 日常使用

- `Enter` / `Return`：发送消息。
- `Shift + Enter`：插入换行。
- 超过 144 个字符或 9 行的消息会尝试按标点分段，**每次只发送一段**，余文留在输入框中；无法安全分段时会提示你手动调整。
- 空白消息点击发送会请求清除聊天气泡；“清空输入”只清空编辑框。
- “发送记录”支持填入编辑、复制、重发和 TXT 导出，最多保留 150 条。
- “快捷短语”最多保存 100 条，直接发送时不调用翻译 API。
- 关闭控制台窗口或按 `Ctrl + C` 可停止程序。

## 界面语言

打开 **设置 → 界面语言**，选择简体中文、English、日本語或 한국어。

默认的“跟随系统”读取**运行程序的 Windows 电脑的显示语言**，不是手机语言；不支持的语言回退为英语。手动选择会保存到电脑，下次打开仍然有效。语言偏好由连接到这台电脑的设备共享，其他已打开的页面刷新后采用新设置。

## 配置翻译服务

打开 **设置 → 翻译服务**。翻译通过运行程序的电脑访问服务商，电脑需要能够连接对应接口。

| 服务 | 必填信息 | 地址和备注 |
| --- | --- | --- |
| MyMemory | 无 | 邮箱可选；单次最多 500 UTF-8 字节，不等于 500 个汉字 |
| DeepL | API Key | 默认 Free 地址；Pro 用户需要更改地址 |
| Azure Translator | API Key | 按资源要求填写 Region；默认使用全球端点 |
| OpenAI 兼容 | API Key | 检查 Base URL 和模型名，接口须支持 Chat Completions |

### MyMemory

选择 MyMemory 即可尝试翻译，无需填写密钥。可选填邮箱。服务可用性和额度由 MyMemory 决定。

### DeepL

填写 DeepL **API** 密钥，按账户类型设置 API Base URL：

```text
Free: https://api-free.deepl.com
Pro:  https://api.deepl.com
```

不要在地址后添加 `/v2/translate`，程序会自动追加。

### Azure Translator

填写密钥和资源要求的 Region，例如 `eastasia`。API Base URL 留空使用：

```text
https://api.cognitive.microsofttranslator.com
```

程序会追加 `/translate?api-version=3.0...`。自定义地址必须与这个路径形式兼容；本版本不自动转换 Azure 自定义域名的路径。

### OpenAI 兼容接口

填写密钥、API Base URL 和模型名。例如：

```text
API Base URL: https://api.openai.com/v1
Model:        gpt-4o-mini
```

这是程序的默认配置示例，不保证你的账户有对应模型权限。使用其他兼容服务时，填写该服务实际提供的 HTTPS 地址及模型 ID。程序会追加 `/chat/completions`，不要重复填写该后缀。

### 设置保存与密钥

- 界面语言、服务选择、地址、模型、Region 和可选邮箱会保存到电脑。
- **API Key 只保留在当前页面内存中**，刷新、关闭页面或切换服务后需要重新填写。
- 切换服务会清空密钥、地址、模型和 Region，以免误用上一服务的配置。
- 只有点击“翻译”才提交待译文本。失败不会清空输入，也不会自动发送消息。
- 服务商可能收取费用或限制额度。翻译文本会发送给你选择的服务商；请自行确认其条款与隐私政策。

## 数据、升级与迁移

Windows 发布版的数据保存在 EXE 旁的 `config` 文件夹，首次运行会按需创建：

| 路径 | 内容 |
| --- | --- |
| `config/config.json` | 连接与外观设置 |
| `config/frontend_state.json` | 历史、短语和界面偏好 |
| `config/data/` | 上传的头像和背景图片 |

升级前退出程序并备份整个 `config` 文件夹。解压新版到新文件夹，再把备份的 `config` 复制到新 EXE 旁。

从旧源码版本迁移时，复制 `HTML osc chat/config` 的内容到新版 `config`。不要上传自己的 `config` 到公开仓库。

## 连接与隐私

默认 Web 监听 `0.0.0.0:5000`，OSC 目标为 `127.0.0.1:9000`。更改 Web 监听地址或端口后需要重启程序；重启后以控制台显示的新地址为准。

本工具**没有登录认证，默认使用 HTTP**，仅适合可信局域网。能访问网页的设备可以操作聊天和共享设置；手机提交到电脑的消息和密钥也经过该局域网连接。请勿将端口转发或公开到互联网。不需要跨设备访问时，可将 Web IP 设置为 `127.0.0.1`。

## 常见问题

| 问题 | 检查方法 |
| --- | --- |
| 是否必须安装 Python？ | Windows 发布包不需要；仅从源码运行或自行构建需要 |
| 启动后没有弹出网页 | 这是预期行为，手动打开控制台显示的地址 |
| 手机打不开网页 | 确认同一局域网、使用电脑的局域网地址，并允许防火墙的专用网络访问；访客 Wi-Fi 可能隔离设备 |
| 端口被占用 | 关闭之前启动的程序；必要时退出后编辑 `config/config.json` 中的 `WEB_PORT`，然后重启 |
| 发送后 VRChat 没显示 | 确认 OSC 已启用、目标 IP/端口正确，并检查 VRChat 的聊天框设置；历史不是送达回执 |
| 翻译提示 401 / 403 | 检查服务、密钥、账户权限，以及 Azure Region 等设置 |
| 翻译提示额度或网络错误 | 检查服务商额度及电脑网络；仍可直接发送原文 |
| 刷新后密钥消失 | 这是设计行为，密钥不会写入磁盘 |
| EXE 无法单独运行 | 请保留完整解压目录和 `_internal`；当前 EXE 未代码签名 |

## 从源码运行

需要 Python 3.10 或更高版本；首次安装依赖需要网络。在仓库根目录运行：

```bat
Start-Windows.cmd
```

也可以手动创建虚拟环境：

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe "HTML osc chat\osc_viewer.py"
```

源码运行的数据目录是 `HTML osc chat/config`。

## 构建 Windows 发布包

在 Windows x64 和 64 位 Python 环境下运行：

```bat
Build-Standalone-Windows.cmd
```

构建结果位于 `dist/VRCChatbox/`。分发**整个文件夹**，不要只分发 EXE。构建脚本不会复制你的运行数据；首次运行使用默认设置。若公开分发二进制，也应提供对应版本源码及许可证。

## 1.4.1：自动配置手机连接
Windows 启动时检查当前程序的防火墙规则。首次运行或移动安装目录、修改 Web 端口后，按需显示 Windows 管理员授权提示；选择“是”后，规则持久保存，后续启动不重复授权。
规则仅允许当前程序、当前 TCP Web 端口（默认 5000）、本地子网访问，适用于专用和公用网络。只提升防火墙配置助手权限，网页服务保持普通权限。绑定回环地址时不添加规则。
取消授权或配置失败不影响电脑本机使用，控制台会提示原因范围，下次启动重试。组织策略或显式阻止规则仍可能阻止连接。
升级：退出旧程序，解压完整新版文件夹，将旧版 config 文件夹复制到新版目录，然后运行 VRCChatbox.exe。请勿仅复制 EXE。手机访问控制台中的 LAN 地址。
