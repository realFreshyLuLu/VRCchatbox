# VRC Chatbox

**컴퓨터나 휴대폰으로 입력하고, VRChat 채팅창에서 대화하세요.**

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · **한국어**

VRC Chatbox는 OSC를 통해 VRChat에 텍스트를 보내는 Windows용 도구입니다. 컴퓨터에서 프로그램을 실행하고 컴퓨터 또는 같은 LAN에 연결된 휴대폰의 브라우저로 사용할 수 있습니다. 전송 전 번역, 공유 기록, 자주 쓰는 문구와 화면 설정을 지원합니다.

> Windows 배포판은 **Python 설치가 필요 없습니다.** 이 저장소의 **Releases**에서 `VRCChatbox-1.4-Windows-x64.zip`을 받으세요. 소스 코드 ZIP은 개발하거나 직접 빌드할 때 사용합니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 여러 기기에서 입력 | 컴퓨터와 같은 LAN의 휴대폰에서 접속 |
| 브라우저 수동 실행 | 시작 시 로컬 및 LAN 주소를 표시하며 브라우저를 자동으로 열지 않음 |
| 4개 화면 언어 | 중국어 간체, 영어, 일본어, 한국어. 선택 저장 및 호스트 표시 언어 자동 감지 |
| 여러 번역 서비스 | MyMemory, DeepL, Azure Translator, OpenAI 호환 API |
| 전송 전 확인 | 번역 결과를 입력창에서 확인하고 수정한 뒤 전송 |
| 이중 언어 메시지 | 원문 + 번역, 번역만, 원문만. 표시 순서 변경 가능 |
| 기록 및 문구 | 컴퓨터에 저장하고 기기 간 공유. 편집, 복사, 재전송, 기록 TXT 내보내기 |
| 화면 설정 | 밝은/어두운 테마, 색상, 아바타, 배경 이미지 |

이 프로그램은 텍스트 전송용입니다. **다른 VRChat 플레이어의 메시지를 수신할 수 없습니다.** 기록은 전송 요청을 나타내며 상대방의 수신을 보장하지 않습니다.

## 빠른 시작

### 1. 다운로드 및 실행

1. Releases에서 Windows x64 압축 파일을 받습니다.
2. 쓰기 권한이 있는 폴더에 **전체 내용**을 압축 해제합니다.
3. `VRCChatbox.exe`를 실행하고 콘솔 창을 열어 둡니다.

EXE 옆의 `_internal` 폴더를 유지하세요. 압축 프로그램 안에서 바로 실행하거나 EXE만 복사하지 마세요.

### 2. 브라우저에서 열기

정상적으로 시작되면 콘솔에 다음과 같은 주소가 표시됩니다.

```text
This computer: http://127.0.0.1:5000/
LAN devices:   http://192.168.1.8:5000/
```

위 주소는 예시입니다. 프로그램이 실제로 표시한 주소를 사용하세요.

- **프로그램을 실행한 컴퓨터:** 브라우저에서 “This computer” 주소를 엽니다.
- **휴대폰 또는 다른 기기:** 같은 LAN에 연결한 뒤 “LAN devices” 주소를 엽니다. 휴대폰의 `127.0.0.1`은 휴대폰 자신을 가리킵니다.
- **주소가 여러 개일 때:** 네트워크 어댑터나 VPN이 여러 개일 수 있습니다. 휴대폰과 같은 서브넷의 주소를 선택하세요.

### 3. VRChat OSC 활성화

VRChat의 OSC 설정에서 OSC를 켭니다. 기본 대상 `127.0.0.1:9000`은 VRChat과 이 프로그램이 같은 컴퓨터에서 실행되는 경우에 사용합니다.

텍스트를 입력하고 **전송**을 누릅니다. 번역하려면 **번역**을 누르고 결과를 확인한 뒤 직접 전송하세요.

## 기본 사용법

- `Enter` / `Return`은 전송, `Shift + Enter`는 줄바꿈입니다.
- 144자 또는 9줄을 넘으면 가능한 경우 문장 부호에서 나눕니다. **한 번에 한 부분만 전송**하며 나머지는 입력창에 남습니다. 적절한 구분점이 없으면 텍스트를 줄이거나 문장 부호를 추가하세요.
- 빈 메시지를 전송하면 채팅 말풍선 지우기를 요청합니다. **입력 지우기**는 입력창만 비웁니다.
- 기록은 최대 150개입니다. 입력창에서 편집, 복사, 재전송, TXT 내보내기를 지원합니다.
- 빠른 문구는 최대 100개를 저장합니다. 문구를 바로 전송할 때는 번역 API를 호출하지 않습니다.
- 콘솔 창을 닫거나 `Ctrl + C`를 누르면 종료됩니다.

## 화면 언어

**설정 → 화면 언어**에서 중국어 간체, 영어, 일본어, 한국어를 선택하세요.

**시스템 설정 따르기**는 휴대폰이 아닌 **프로그램을 실행 중인 Windows 컴퓨터의 표시 언어**를 읽습니다. 지원하지 않는 언어는 영어로 표시합니다. 직접 선택한 언어는 컴퓨터에 저장되며 다음 실행에도 유지됩니다. 연결된 기기가 이 설정을 공유하며 다른 열린 페이지에는 새로고침 후 적용됩니다.

## 번역 서비스 설정

**설정 → 번역 서비스**를 엽니다. 번역 요청은 호스트 컴퓨터에서 전송하므로 컴퓨터가 해당 서비스에 연결할 수 있어야 합니다.

| 서비스 | 필수 항목 | 참고 |
| --- | --- | --- |
| MyMemory | 없음 | 이메일은 선택 사항. 한 번에 최대 500 UTF-8 바이트이며 한글 500자를 뜻하지 않음 |
| DeepL | API Key | 기본값은 Free 주소. Pro는 주소 변경 필요 |
| Azure Translator | API Key | 리소스 요구 사항에 따라 Region 입력. 기본값은 글로벌 엔드포인트 |
| OpenAI 호환 | API Key | 주소와 모델 ID 확인. Chat Completions 지원 필요 |

### MyMemory

서비스를 선택하면 키 없이 번역을 시도할 수 있습니다. 이메일은 선택 사항입니다. 사용 가능 여부와 할당량은 MyMemory에서 정합니다.

### DeepL

DeepL **API** 키를 입력하고 계정 종류에 맞는 API Base URL을 사용하세요.

```text
Free: https://api-free.deepl.com
Pro:  https://api.deepl.com
```

`/v2/translate`는 프로그램이 붙이므로 입력하지 마세요.

### Azure Translator

키와 리소스에 필요한 Region(예: `eastasia`)을 입력합니다. API Base URL을 비워 두면 다음 주소를 사용합니다.

```text
https://api.cognitive.microsofttranslator.com
```

프로그램은 `/translate?api-version=3.0...`을 붙입니다. 사용자 지정 주소는 이 경로 형식과 호환되어야 합니다. 이 버전은 Azure 사용자 지정 도메인용 경로를 자동으로 변환하지 않습니다.

### OpenAI 호환 API

키, API Base URL, 모델 ID를 입력하세요. 프로그램의 기본 설정 예시는 다음과 같습니다.

```text
API Base URL: https://api.openai.com/v1
Model:        gpt-4o-mini
```

이 예시는 계정의 모델 이용 권한을 보장하지 않습니다. 다른 호환 서비스를 사용할 때는 해당 서비스의 실제 HTTPS 주소와 모델 ID를 입력하세요. `/chat/completions`는 자동으로 붙으므로 중복 입력하지 마세요.

### 설정 저장과 키

- 화면 언어, 서비스, 주소, 모델, Region, 선택 사항인 이메일은 컴퓨터에 저장합니다.
- **API 키는 현재 페이지의 메모리에만 유지합니다.** 새로고침, 페이지 닫기, 서비스 변경 후에는 다시 입력해야 합니다.
- 서비스 변경 시 이전 설정을 잘못 사용하지 않도록 키, 주소, 모델, Region을 지웁니다.
- **번역**을 누를 때만 번역할 텍스트를 제출합니다. 실패해도 입력은 유지되며 메시지를 자동 전송하지 않습니다.
- 서비스에서 비용을 청구하거나 사용량을 제한할 수 있습니다. 텍스트는 선택한 서비스로 전송됩니다. 해당 약관과 개인정보 처리방침을 확인하세요.

## 데이터, 업데이트 및 이전

Windows 배포판은 EXE 옆의 `config` 폴더에 필요한 파일을 생성합니다.

| 경로 | 내용 |
| --- | --- |
| `config/config.json` | 연결 및 화면 설정 |
| `config/frontend_state.json` | 기록, 문구, 화면 환경 설정 |
| `config/data/` | 업로드한 아바타 및 배경 이미지 |

업데이트 전에 프로그램을 종료하고 `config` 폴더 전체를 백업하세요. 새 버전을 새 폴더에 압축 해제하고 백업한 `config`를 새 EXE 옆에 복사합니다.

이전 소스 버전에서 옮길 때는 `HTML osc chat/config`의 내용을 복사하세요. 개인 `config`를 공개 저장소에 올리지 마세요.

## 네트워크 및 개인정보

기본 웹 수신 주소는 `0.0.0.0:5000`, OSC 대상은 `127.0.0.1:9000`입니다. 웹 수신 주소나 포트 변경 후에는 재시작이 필요합니다. 재시작 후 표시되는 새 주소를 사용하세요.

이 프로그램은 **로그인 인증이 없고 기본적으로 HTTP를 사용**합니다. 신뢰할 수 있는 LAN에서만 사용하세요. 접속 가능한 기기는 채팅과 공유 설정을 조작할 수 있으며, 휴대폰의 메시지와 키도 해당 LAN 연결을 통해 전달됩니다. 포트 포워딩으로 인터넷에 공개하지 마세요. 컴퓨터에서만 사용할 경우 Web IP를 `127.0.0.1`로 설정할 수 있습니다.

## 문제 해결

| 문제 | 확인할 내용 |
| --- | --- |
| Python이 필요한가요? | Windows 배포판에는 필요 없습니다. 소스 실행 또는 빌드에만 필요합니다 |
| 브라우저가 열리지 않아요 | 정상 동작입니다. 콘솔의 주소를 직접 여세요 |
| 휴대폰에서 접속이 안 돼요 | 같은 LAN, 컴퓨터 LAN 주소, 방화벽의 개인 네트워크 허용을 확인하세요. 게스트 Wi-Fi는 기기 간 연결을 차단할 수 있습니다 |
| 포트가 사용 중이에요 | 이전 실행을 종료하세요. 필요하면 프로그램 종료 후 `config/config.json`의 `WEB_PORT`를 수정하고 재시작하세요 |
| VRChat에 메시지가 안 보여요 | OSC 활성화, 대상 IP/포트, VRChat 채팅창 설정을 확인하세요. 기록은 수신 확인이 아닙니다 |
| 번역 오류 401 / 403 | 서비스, 키, 계정 권한, 필요한 Azure Region을 확인하세요 |
| 할당량 또는 네트워크 오류 | 서비스 사용량과 컴퓨터 연결을 확인하세요. 원문은 계속 전송할 수 있습니다 |
| 새로고침하면 키가 사라져요 | 디스크에 키를 저장하지 않는 설계입니다 |
| EXE만으로 실행이 안 돼요 | `_internal`을 포함한 전체 폴더가 필요합니다. 현재 EXE에는 코드 서명이 없습니다 |

## 소스에서 실행

Python 3.10 이상이 필요합니다. 최초 의존성 설치에는 인터넷 연결이 필요합니다. 저장소 루트에서 실행하세요.

```bat
Start-Windows.cmd
```

수동으로 준비하려면:

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe "HTML osc chat\osc_viewer.py"
```

소스 실행 시 데이터는 `HTML osc chat/config`에 저장합니다.

## Windows 배포판 빌드

Windows x64와 64비트 Python 환경에서 실행하세요.

```bat
Build-Standalone-Windows.cmd
```

결과는 `dist/VRCChatbox/`에 생성됩니다. EXE만이 아닌 **폴더 전체**를 배포하세요. 빌드 스크립트는 개인 실행 데이터를 복사하지 않으며 처음 실행할 때 기본 설정을 사용합니다. 바이너리를 배포할 때는 해당 버전의 소스와 라이선스도 함께 제공하세요.

## 검증 및 피드백

1.4에서는 백엔드, 데이터 저장, OSC 요청 회귀 테스트와 패키징한 EXE 실행, 브라우저 언어 전환을 확인했습니다. 번역 요청과 응답은 모의 서비스로 검증했습니다. 실제 유료 계정, VRChat 내 수신 결과, 실물 휴대폰 연결은 충분히 실측하지 않았습니다.

Issue를 작성할 때 프로그램 및 Windows 버전, 재현 절차, 민감 정보를 제거한 오류 메시지를 포함하세요. **API 키, 개인 채팅 기록, 개인 설정 전체를 게시하지 마세요.**
