# VRC Chatbox

**VRChat の無言勢プレイヤーが、VR 中にスマートフォンで文字を入力してフレンドと交流するためのツールです。**

[简体中文](README.md) · [English](README.en.md) · **日本語** · [한국어](README.ko.md)

VRC Chatbox は、OSC を使って VRChat にテキストを送信する Windows 向けツールです。PC でアプリを起動し、PC のブラウザーや同じ LAN 内のスマートフォンから操作できます。送信前の翻訳、共有履歴、定型文、外観の設定に対応しています。

> Windows 配布版は **Python のインストール不要**です。このリポジトリの **Releases** から `VRCChatbox-1.4-Windows-x64.zip` をダウンロードしてください。ソースコードの ZIP は開発・ビルド用です。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 複数デバイスで入力 | PC や同じ LAN 内のスマートフォンからアクセス |
| ブラウザーを手動で開く | 起動時に PC 用・LAN 用のアドレスを表示。ブラウザーは自動起動しません |
| 4 言語の UI | 簡体字中国語・英語・日本語・韓国語。設定の保存とホストの表示言語の自動検出 |
| 翻訳サービス | MyMemory、DeepL、Azure Translator、OpenAI 互換 API |
| 送信前に確認 | 翻訳結果を入力欄で確認・編集してから送信 |
| 二言語表示 | 原文＋訳文、訳文のみ、原文のみ。表示順も変更可能 |
| 履歴と定型文 | PC に保存し各端末で共有。編集・コピー・再送信、履歴の TXT 書き出し |
| 外観 | ライト／ダークテーマ、色、アイコン、背景画像 |

本ツールは送信用です。**他の VRChat プレイヤーのメッセージは受信できません。** 履歴は送信処理の記録であり、相手の受信を保証するものではありません。

## はじめに

### 1. ダウンロードと起動

1. Releases から Windows x64 版をダウンロードします。
2. 書き込み可能なフォルダーに ZIP の**全内容**を展開します。
3. `VRCChatbox.exe` を起動し、コンソールウィンドウを開いたままにします。

EXE の隣にある `_internal` フォルダーは必要です。圧縮ファイル内から直接起動したり、EXE だけを移動したりしないでください。

### 2. ブラウザーで開く

起動に成功すると、コンソールに次のようなアドレスが表示されます。

```text
This computer: http://127.0.0.1:5000/
LAN devices:   http://192.168.1.8:5000/
```

これは例です。実際に表示されたアドレスを使用してください。

- **起動した PC で使う：** 「This computer」のアドレスをブラウザーで開きます。
- **スマートフォンなどで使う：** 同じ LAN に接続し、「LAN devices」のアドレスを開きます。スマートフォンの `127.0.0.1` はスマートフォン自身を指すため、PC には接続できません。
- **複数のアドレスが出る：** 複数のネットワークアダプターや VPN がある場合です。スマートフォンと同じサブネットのアドレスを選んでください。

### 3. VRChat の OSC を有効にする

VRChat の OSC 設定で OSC を有効にします。既定の送信先 `127.0.0.1:9000` は、VRChat と本アプリが同じ PC で動作する場合の設定です。

テキストを入力して「送信」を押します。翻訳する場合は「翻訳」を押し、結果を確認してから送信してください。

## 基本操作

- `Enter` / `Return` で送信、`Shift + Enter` で改行します。
- 144 文字または 9 行を超える場合は、可能なら句読点で分割します。**1 回の操作で送信するのは 1 区間だけ**で、残りは入力欄に残ります。分割位置が見つからない場合は、文章を短くするか句読点を追加してください。
- 空のメッセージを送信するとチャットの吹き出しの消去を要求します。「入力を消去」は入力欄だけを消去します。
- 履歴は最大 150 件。入力欄での編集、コピー、再送信、TXT 書き出しができます。
- 定型文は最大 100 件。直接送信では翻訳 API を呼び出しません。
- 終了するにはコンソールを閉じるか `Ctrl + C` を押します。

## 表示言語

**設定 → 表示言語** で簡体字中国語・英語・日本語・韓国語を選択できます。

「システム設定に従う」は、スマートフォンではなく**アプリが動作する Windows PC の表示言語**を参照します。未対応の言語では英語を使います。手動の選択は PC に保存され、次回も適用されます。設定は接続デバイス間で共有されます。他の開いているページには再読み込み後に反映されます。

## 翻訳サービスの設定

**設定 → 翻訳サービス** を開きます。翻訳リクエストは PC から送信するため、PC がサービスに接続できる必要があります。

| サービス | 必須項目 | 補足 |
| --- | --- | --- |
| MyMemory | なし | メールは任意。1 回 500 UTF-8 バイトまでで、日本語 500 文字ではありません |
| DeepL | API Key | 既定は Free 用。Pro では URL を変更します |
| Azure Translator | API Key | リソースに応じて Region が必要。既定はグローバルエンドポイント |
| OpenAI 互換 | API Key | URL とモデル ID を確認。Chat Completions 対応が必要 |

### MyMemory

選択するだけでキーなしの翻訳を試せます。メールアドレスは任意です。利用可能な範囲や上限は MyMemory に従います。

### DeepL

DeepL **API** キーを入力し、アカウントに合わせて API Base URL を指定します。

```text
Free: https://api-free.deepl.com
Pro:  https://api.deepl.com
```

`/v2/translate` は自動で追加されるため、入力しないでください。

### Azure Translator

キーと、リソースで必要な Region（例：`eastasia`）を入力します。API Base URL が空欄の場合は次を使用します。

```text
https://api.cognitive.microsofttranslator.com
```

アプリは `/translate?api-version=3.0...` を追加します。カスタム URL はこのパス構成に対応する必要があります。本バージョンは Azure カスタムドメイン向けのパスを自動変換しません。

### OpenAI 互換 API

キー、API Base URL、モデル ID を入力します。アプリの既定値の例：

```text
API Base URL: https://api.openai.com/v1
Model:        gpt-4o-mini
```

これは利用権限を保証するものではありません。他の互換サービスを使う場合は、そのサービスの HTTPS URL とモデル ID を指定してください。`/chat/completions` は自動追加されるため、重複して入力しないでください。

### 保存される設定とキー

- 表示言語、サービス、URL、モデル、Region、任意のメールアドレスは PC に保存します。
- **API キーは現在のページのメモリー内でのみ保持**します。再読み込み、ページを閉じた後、サービス変更後は再入力が必要です。
- サービスを変更すると、誤用を防ぐためキー・URL・モデル・Region を消去します。
- 「翻訳」を押したときだけ翻訳用テキストを送信します。失敗しても入力は残り、自動送信はしません。
- サービス側で料金や利用制限が発生する場合があります。テキストは選択した事業者に送信されます。利用規約とプライバシーポリシーを確認してください。

## データ・更新・移行

Windows 配布版は EXE の隣の `config` に必要なファイルを作成します。

| パス | 内容 |
| --- | --- |
| `config/config.json` | 接続と外観の設定 |
| `config/frontend_state.json` | 履歴・定型文・表示設定 |
| `config/data/` | アップロードしたアイコンや背景画像 |

更新前にアプリを終了し、`config` 全体をバックアップしてください。新版を新しいフォルダーに展開し、その EXE の隣へ `config` をコピーします。

以前のソース版から移行する場合は `HTML osc chat/config` の内容をコピーします。個人の `config` を公開リポジトリにアップロードしないでください。

## 接続とプライバシー

既定の Web 待受は `0.0.0.0:5000`、OSC 送信先は `127.0.0.1:9000` です。Web の待受アドレス・ポートを変更したら再起動し、表示された新しいアドレスを使ってください。

本アプリは**ログイン認証がなく、既定で HTTP を使用**します。信頼できる LAN 内でのみ使用してください。アクセスできる端末はチャットと共有設定を操作できます。スマートフォンから送るテキストやキーも LAN 接続を経由します。インターネットへの公開やポート転送はしないでください。PC 内だけで使う場合は Web IP を `127.0.0.1` に設定できます。

## よくある質問

| 症状・質問 | 確認すること |
| --- | --- |
| Python は必要？ | Windows 配布版では不要。ソースからの実行・ビルド時のみ必要です |
| ブラウザーが開かない | 仕様です。コンソールの URL を手動で開いてください |
| スマートフォンから接続できない | 同じ LAN、PC の LAN アドレス、ファイアウォールのプライベートネットワーク許可を確認。ゲスト Wi-Fi は端末間通信を制限する場合があります |
| ポートが使用中 | 以前の起動分を終了。必要なら停止後に `config/config.json` の `WEB_PORT` を編集し再起動します |
| VRChat に表示されない | OSC、送信先 IP・ポート、VRChat のチャットボックス設定を確認。履歴は受信確認ではありません |
| 翻訳が 401 / 403 になる | サービス、キー、権限、Azure の Region などを確認します |
| 利用上限・ネットワークエラー | 利用枠と PC の接続を確認。原文は引き続き送信できます |
| 再読み込みでキーが消える | キーをディスクに保存しない設計です |
| EXE 単体で動かない | `_internal` を含む全ファイルが必要です。現在の EXE はコード署名されていません |

## ソースから実行

Python 3.10 以上が必要です。初回の依存関係のインストールにはインターネット接続を使います。リポジトリのルートで実行：

```bat
Start-Windows.cmd
```

手動で準備する場合：

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe "HTML osc chat\osc_viewer.py"
```

ソース実行時の保存先は `HTML osc chat/config` です。

## Windows 配布版をビルド

Windows x64 と 64 ビット Python 環境で実行します。

```bat
Build-Standalone-Windows.cmd
```

出力先は `dist/VRCChatbox/` です。EXE だけでなく**フォルダー全体**を配布してください。ビルドスクリプトは実行時の個人データをコピーせず、初回は既定の設定を使います。バイナリーを配布する際は、対応するソースコードとライセンスも提供してください。
